# Changelog

## 2026-09-19 - v1.4.0-Release

### Changes

- Add Guild/Officer Chat with scrollable history, day separators, class-coloured names, click-to-whisper and a message box. Includes Discord-linked messages and respects EllesmereUI chat privacy.
- Add a Guild Health Info page showing Blizzard guild challenges, message of the day, guild information and news with item tooltips. Officers can open Blizzard's controls to edit guild text.
- Open Blizzard's Guild Finder listing editor from Guild Health. Officers receive daily expiry reminders with Dismiss/Open buttons and a configurable threshold in General settings (default: below 10 days).
- Prepare rank changes from roster details, then execute them using the Macro Tool keybind or action-bar macro.
- Add a Toggle Guild Paragon keybinding, with its current shortcut and a Keybindings button in General settings.
- Show who promoted, demoted, removed or invited a member when Blizzard provides a clear matching record.
- Review Guild Finder applications inside Guild Paragon, with class-coloured names, applicant details and approval or decline after confirmation. Checks and responses pause during combat, loading and protected instances.
- Browse Blizzard applicant history and see who handled applications through Guild Paragon. Up to 200 response records per guild are kept for 30 days and sync privately between eligible officers.
- Add application counts, Review/Dismiss popups and login/new-applicant reminders for authorised officers, with reminder muting until reload.

- Keep distinct rank changes separate when merging Event Logs.
