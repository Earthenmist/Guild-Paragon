# 1.11.1-Release

## Changes
- None.

## Fixes
- WoW Forever: Guild Sync no longer lists your own character as a peer. Sync now uses your full First Last name, so data other players send you is recognised.
- WoW Forever: rank changes from the roster now work for members with a First Last name, instead of saying the name cannot be used in a macro.
- WoW Forever: the Guild Invite button no longer causes an error. Forever only allows guild invites from Blizzard's own UI, so the button is hidden there; type /ginvite followed by the full name in chat instead.

## Known issues
- WoW Forever: recruitment queue invites and the Ban List cooldown invite are unavailable, for the same reason as the Guild Invite button.
