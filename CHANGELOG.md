# Changelog

## 2026-09-10 - v1.3.1-Release

### Changes

- Companion data now loads from the separate Guild Paragon Companion Data
  addon, created by Companion 1.0.18. Restart WoW after first setup and enable
  that data addon; later syncs need only /reload.

### Fixes

- Companion no longer needs to modify files inside Guild Paragon's installed
  package, avoiding the cause of CurseForge's modified-files warning.

### Known issues

- None.
