# Changelog

## 2026-09-20 - v1.4.2-Release

### Changes

- Pick birthdays using named months and a day grid instead of ambiguous number boxes. Existing birthdays are preserved; Save and Clear still control changes. Upcoming birthdays also show a day and named month, independent of date-format settings.

- Choose the default date display, DD-MM-YYYY or MM-DD-YYYY in General settings. The Joined field displays and accepts your chosen format; stored data, exports and other date-entry formats are unchanged.

- Configure the last four roster columns in Settings > General. Choose Nickname, Alt / Main, any of the four notes, Current Location, M+ Score or Achievement Points. Each choice can appear only once. Existing unique column choices are preserved.
- Column headers and sorting follow your selections. Officer-only notes retain permission checks. Current Location is shown for online members; M+ scores follow the Guild Health season-start setting and show - when unrated, and achievement points use the latest available roster data.
